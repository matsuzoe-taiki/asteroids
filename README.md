Asteroids

This project was created as part of the Build Asteroids course on Boot.dev.

Asteroids is a simple 2D game where the player must avoid incoming asteroids while shooting and destroying them.

How to Play

- Press W to move forward.
- Press S to move backward.
- Press A and D to rotate the player.
- The player can shoot bullets to destroy asteroids.

Game Mechanics

When a bullet hits an asteroid, the asteroid splits into smaller asteroids.

The smaller asteroids can also be shot and split again. Once an asteroid reaches its minimum size, shooting it will destroy it completely.

Avoid colliding with the asteroids while destroying as many as you can!
